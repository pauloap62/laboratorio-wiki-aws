Na pasta RAW feita pelo Felipe especialista da DIO, foram encontrados arquivos dos diferentes formatos ( .png, .csv, .pdf) simulando um arquivo desorganizado de uma empresa, cujo se decidiu organizar tudo para futuramente ter um banco de dados que pudesse ser verificado e analisado para futuras melhorias, baseando-se nessa premissa e usando somente os programas da AWS ( Amazon Web Services) podemos começar da seguinte forma. 

 Primeiro precisamos transferir todos os arquivos para um local onde pudesse ser alocado de forma segura e que pudesse ser acessado a qualquer hora sem maiores problemas, para isso usaríamos o Amazon S3, o qual seria perfeito para o armazenamento sem medo de que possa ser corrompido ou perdido em algum momento, pois o mesmo guarda o histórico das versões intactas de cada arquivo e possui criptografia para proteger os dados. ao enviar os arquivos para o Amazon S3 ele enviara os mesmos para o AWS Lambda que le os aquivos para identificar seu formato, identificando o formato ele tomara as seguintes medidas. 

caso for .PNG ou .PDF ele acionaria o AWS textract que vai extrair e converter em textos os arquivos enviados,  

caso for .CSV o próprio AWS Lambda lê as colunas e os dados corretamente e enviaria para o próximo passo. 

quanto ao problema da preocupação de ser enviado um arquivo que esteja corrompido ou com problemas na leitura poderíamos usar o Amazon Cloudwatch, que funciona como um registro de tudo que acontece, ao identificar algum erro o mesmo alerta a área técnica para a avaliação do que está acontecendo junto com o serviço de Quarentena aonde o arquivo é enviado para que uma equipe o analise pessoalmente e evitando que seja perdido, após a extração de todos os arquivos deveríamos etiquetá-los com as seguintes informações nome original do arquivo, quem o envio, qual equipe que participou de sua confecção, valores envolvidos, tipo de arquivo( ata ou planilha de vendas). após esse procedimento os arquivos seriam salvos em formato .json em um novo bucket no S3. 

após esses procedimentos poderíamos trabalhar usando o Amazon Bedrock que possui o recurso de Knowledge Bases, que fatia os textos e os representa matematicamente em um banco vetorial ( Amazon Open Search Serverless) assim quando um usuária buscar por alguma informação ele vai conseguir encontrar corretamente a informação desejada, salientando que a I.A responder a pesquisa citando exatamente a fonte e a página do documento original desta forma poderíamos usar os recursos da AWS para armazenar, catalogar, classificar e buscar os arquivos de uma forma totalmente efetiva e econômica uma vez que não precisaríamos ter gastos a mais com instancias físicas para guardar arquivos, e também melhoraríamos o banco de dados da empresa.
